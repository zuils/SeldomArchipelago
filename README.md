# About This Fork

This is a public beta for some features that may one day become official, should players enjoy them.

Built off of the [official Archipelago branch](https://github.com/Seldom-SE/archipelago_terraria_client), developed and managed by Seldom.
If you're unclear about what Archipelago is, check out that page's README.

# Usage

## Full Client (All Features)
Playing with access to all features will require a fresh multiworld generated with the packaged .apworld.
The methodology for producing such is identical to that of most custom games; download the .apworld, then install it and generate template YAMLs through your AP client.
You'll know it worked if the resulting game is not just "Terraria," but instead "Terraria_Desp_Beta."

## Lite Client (Marked Features Only)
The Lite client can connect to pre-existing games generated from AP's official/stable branch (such as the big async or ones generated through archipelago.gg). You can switch to and from this client without much issue.
